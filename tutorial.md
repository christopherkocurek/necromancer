# The Necromancer Tutorial (Beta v1.1)

Version: 2026-02-14

This tutorial is a practical first-run script for internal testers and new players.

## 1. One-Minute Setup

1. Launch the game build.
2. Start a new character.
3. If uncertain, choose a survivable setup (durable race/house and balanced stats).

Goal for first session:
- survive long enough to learn loop discipline, not to force a heroic run.

## 2. The First 10 Turns

1. Confirm movement keys and wait key (`.`).
2. Identify a safe retreat line (corridor/doorway).
3. Pick up immediate upgrades (`G`) and equip (`I` then equip action).
4. Avoid open-room brawls until you can control engagement geometry.

## 3. The Core Survival Loop

Repeat:
1. Scout edge of unknown tiles.
2. Pull enemies into favorable terrain.
3. Spend resources before collapse, not after.
4. Rest only when safe and relevant.
5. Descend once current floor is no longer giving useful returns.

## 4. Controls You Actually Need

- Move: `W/A/S/D`, arrows, or `H/J/K/L`
- Diagonal: `Y/U/B/N`
- Wait: `.`
- Interact / stairs: `Enter`
- Pick up: `G`
- Inventory: `I`
- Tome: `T` or `@`
- Voice/Lore: `V`
- Look: `X`
- Minimap: `M`
- Pause/settings: `Esc`
- Hotbar cast/bind: `1-8`

## 5. New-Player Doctrine

1. **Fight fewer things.**
Winning runs are usually selective runs.

2. **Preserve exits.**
Never commit to a tile that removes your retreat line without clear payoff.

3. **Spend on today.**
XP should fix current failure mode first.

4. **Protect light.**
Darkness multiplies mistakes.

5. **Use voice deliberately.**
Voice is strongest when used to stop losses, not pad winning fights.

## 6. Beta v1.1 Objective

In this beta, victory requires:
1. Get **Thrain's map and key**.
2. Return to floor 1.
3. Take upstairs.

If done correctly, you receive the beta escape message and return to menu.

## 7. Common Failure Patterns

- Dying in open multi-angle rooms after over-committing.
- Hoarding voice/utility until too late.
- Entering deeper floors without stable light plan.
- Buying elegant long-term upgrades while current defenses are weak.

## 9. Session Completion Criteria (Internal)

A minimally valid session should include:
1. one complete character start,
2. at least one floor descent,
3. at least one ability activation,
4. at least one inventory/equipment interaction,
5. one clear balance or UX note.

That is enough to generate useful signal.
